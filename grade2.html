Lesson 1: Understanding Place Value

Place value tells us the value of a digit based on its position in a number.

Ones and Tens

A two-digit number has a tens place and a ones place. Ten ones make one ten.

Example: Understanding the number 24
24 = 2 tens + 4 ones

The digit 2 represents 20, while the digit 4 represents 4.

Therefore: 20 + 4 = 24

Worked Example

What is the value of the digit 5 in 57?

57 = 50 + 7
Answer: 50

The digit 5 is in the tens place, so its value is 50.

Practice Exercise

  1. Write 36 as tens and ones.
  2. What is the value of 4 in 48?
  3. How many tens are there in 72?
  4. Which is greater: 56 or 65?
  5. Write the number represented by 3 tens and 8 ones.
